# 用友ERP沙盘模拟系统（企业1专属版）

![版本](https://img.shields.io/badge/版本-0.2.0-blue)

## 项目概述

用友ERP沙盘模拟系统是一款基于现代Web技术开发的企业运营模拟软件，用于《创新实践及科研训练》（创新创业实践）课程教学。系统模拟企业1全流程运营，帮助学生理解企业管理的核心概念和运营逻辑，提升综合管理能力和决策水平。

按课程要求，本系统为**企业1专属版**：仅保留企业1作为唯一运营主体，无多企业竞争设定；广告投放规则采用课程修改项（一次投放覆盖本地+区域市场、P1+P2产品）；本期运营仅开放 P1/P2 产品与 P2 研发。

### 核心功能

- **财务中心**：现金流量可视化、长/短期贷款（含还本付息生命周期）、资金贴现（7:1）、应付税金下年初交纳、年度利润表
- **生产中心**：厂房与生产线管理（购买分期付款、转产、出售残值规则）、P2 分期研发（1M/季×6季）、折旧计提
- **物流中心**：原材料采购（R1/R2提前1季、R3/R4提前2季，到货入库付款）、库存管理
- **营销中心**：市场开拓（年度投资模型+维持规则）、ISO认证、广告投放（修改后规则）、订货会订单池、订单交付
- **运营流程**：年初/季度/年末操作步骤、季度推进、第四年结束模拟
- **运行控制表**：按年导出 `第X年运行控制表.csv`（年初4项+季度20项×4+年末6项，按课程格式填充数据）
- **教学辅助**：内置规则说明弹窗、运营暂停/继续（讲解模式）、存档（自动+手动）、操作日志导出

## 安装指南

```bash
git clone <项目仓库地址>
cd ie-research-simulation
npm install
npm run dev        # 开发服务器 http://localhost:3000
npm test           # 运行单元测试
```

## 部署（GitHub Pages）

通过 GitHub Actions 自动部署：推送 `main` 分支（或在 Actions 页手动触发 workflow）即自动完成 测试 → 静态导出构建 → 发布。

**首次启用需手动设置一次**：仓库 Settings → Pages → Source 选择 **"GitHub Actions"**，之后推送 main 即可访问 `https://piggywu981.github.io/ie-research-simulation/`。

- 构建命令带 `DEPLOY_TO_PAGES=1` 环境变量启用静态导出与 `basePath`（见 `next.config.js`），本地开发与 `npm start` 不受影响
- 运营数据存于浏览器 localStorage，不同设备互不相通；跨设备请使用系统内导出的存档/CSV 文件

## 使用说明

### 系统初始状态（遵循课程标准）

- **财务**：现金20M，应收账款15M（4Q账期），长期贷款40M，应交税1M；总资产105M = 负债41M + 权益64M
- **生产**：大厂房（自有40M）+ 小厂房（租赁3M/年）各1个，各配1条全自动生产线（设备净值合计13M）；P1在制品4个
- **物流**：R1原料3个，P1成品3个
- **营销**：本地市场准入，P1生产资格；区域/国内/亚洲/国际市场与ISO9000/ISO14000均未取得

### 运营流程

1. **年初**：新年度规划会议 → 投放广告 + 参加订货会（生成订单池）→ 制定新年度计划 → 支付应付税
2. **季度**：季初盘点 → 短贷还本付息 → 原料下单/到货 → 生产（开工投料+加工费1M）→ 交货 → 研发/行政费等
3. **年末**：长贷付息/还本 → 设备维护费 → 厂房租金 → 计提折旧 → 市场开拓/ISO投资（各1M/年，未维护则丧失市场）→ 结账（利润表与所得税计入应付税金）
4. **导出**：运营流程页可随时导出已完成年度的运行控制表 CSV

### 关键规则（含课程修改项）

- **广告（修改项）**：投放一次同时覆盖本地+区域市场、P1+P2产品；金额决定可选订单数量（每1M解锁2张）；仅年初第1季度可投放
- **贷款**：长贷年末申请（3年期10%，每次20M最多40M）；短贷Q1/Q3放贷（1年期5%，到期一次还本付息）；无高利贷
- **贴现**：应收款随时可贴现，7M付1M贴息
- **市场开拓**：年末操作，1M/年/市场，可中断；已准入市场每年投1M维持，否则放弃

详细规则见系统内"规则说明"弹窗。

## 项目结构

```
src/
├── app/                 # 页面（主界面 + 财务中心）
├── components/          # 生产/物流/营销/运营中心、规则弹窗、贴现面板、存档面板
├── store/               # enterpriseStore（Zustand 全局状态与业务规则）
├── utils/               # rules（规则纯函数）、controlTable（运行控制表导出）
├── config/              # marketDemand（订单池配置，教师可修改需求量）
├── types/               # TypeScript 类型定义
docs/
├── superpowers/specs/   # 设计规格
├── superpowers/plans/   # 实现计划
tests/                   # Vitest 单元测试（规则计算、控制表、端到端）
directions/              # 课程方向资料
```

## 开发说明

- 提交规范：语义化提交信息（feat/fix/docs...）
- 测试：`npm test`（Vitest），覆盖折旧、税金、贷款生命周期、贴现、原料到货跨年、订单池、控制表导出等核心规则
- 订单池初始数值为拟定值（课程未提供官方需求预测表），可在 `src/config/marketDemand.ts` 中按课程实际数据修改

## 项目背景

《创新实践及科研训练》面向智能制造、机械工程等专业，通过模拟企业运营提升学生综合管理能力。考核：总评成绩 = 平时表现20% + 模拟企业运营70% + 实践报告10%。

课程参考资料见 `.agents/documents/`（规则说明文件、企业1专属版实现计划等），权威课程资料见 `directions/`。
