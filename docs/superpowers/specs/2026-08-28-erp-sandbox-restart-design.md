## 4. 总体设计

### 4.1 绝对季度索引

引入 `absoluteQuarter = (year - 1) * 4 + quarter`（year、quarter 为 1 基）。原料到货、短贷到期、研发进度等一切跨期调度一律用绝对索引存储与比较，根治跨年 bug。旧存档不含该字段，按 4.14 迁移。

### 4.2 贷款模型（重做为台账）

`Loan { id, kind: 'long' | 'short', principal, rate, drawnAbsQuarter, termQuarters }`，替代现有单一 `longTermLoan/shortTermLoan` 数值。

- **长贷**：仅 Q4 可申请；每次 20M；未还本余额上限 40M；年息 10%；期限 3 年。每年年末（Q4 结账序列）对每笔存续长贷：支付利息 `principal × 10%`，`term -= 1`；`term == 0` 时还本。利息、还本日志标到控制表"年末-1 支付利息/更新长期贷款/申请长期贷款"。
- **短贷**：仅 Q1、Q3 季初可申请（对应"1月、6月放贷"）；每次 20M；未还本余额上限 40M；年息 5%；期限 4 个季度（绝对索引 `dueAbs = drawnAbs + 4`）。每季度初（控制表行 2"更新短贷/还本付息"）检查到期：一次还本付息 `principal × 1.05`。
- 额度校验按"未还本余额"累计；拒绝时给出明确错误消息（见第 6 节）。

### 4.3 资金贴现

新 action `discountReceivable(amount)`：`amount` 为 7 的倍数且 ≤ 应收账款余额；现金 `+ amount × 6/7`，应收 `- amount`，贴息 `amount/7` 计入财务费用。财务中心新增输入面板（含 7 的倍数提示与可贴现余额）。日志标到控制表行 11"更新应收账款/应收账款收现"。

### 4.4 折旧

年末（Q4 结账序列，控制表"年末-4 计提折旧"）：对每条生产线，若其**安装完工年份 < 当前年**且本年未出售：`净值 ≥ 3M` 时 `折旧 = floor(净值 / 3)`，否则 `折旧 = 1M`。净值扣减（`netValue` 字段），折旧为非现金费用，进年度利润表"折旧"行，同时设备账面价值联动（机器和设备合计 = Σ 净值 + 在建设备投入）。厂房不提折旧（课程 _21、_16 页确认：初始折旧 4M = floor(13/3)）。

### 4.5 年度利润表与税金

按课程 _16 页结构逐年累计（`annualLedger`，随 Q4 结账清零并归档进 `yearlyReports`）：

```
销售收入（deliverOrder 时按 order.totalAmount 累计）
− 直接成本（成品出库时按产品成本累计：P1=2M、P2=3M）
= 毛利
− 综合费用（行政费、广告、市场开拓、研发、ISO、转产费、维护费、租金、其他）
= 折旧前利润
− 折旧
= 支付利息前利润
− 财务费用（长/短贷利息 + 贴现贴息；贴现收入为正）
± 额外收支（出售生产线残值差额等）
= 税前利润
− 所得税（max(0, 税前利润) × 25%，向下取整）→ 计入应付税金
= 净利润
```

Q4 结账时计算所得税并累加 `taxesPayable`；**下一年 Q1 年初**"支付应付税"步骤从现金支付并记日志（页头"核心任务：待支付应付税"改为真实数据驱动）。净利润年末结转利润留存。

### 4.6 加工费

`startProduction` 启动生产时：校验原料（P1=1×R1，P2=1×R1+1×R2）与现金 ≥1M，原料入库扣减、在制品 +1、现金扣 1M/产品，日志标到控制表行 10"开始下一批生产"（格式 `-1M(P1,全自动)`）。完工入库（行 7）记非现金注记 `-2M(P1,全自动)` 式生产成本。

### 4.7 产品研发（仅 P2）

P2：总 6M、周期 6Q。状态 `idle / active / completed`。启动后每季度自动支付 1M（现金不足则当季中断并提示，后续季度现金充足自动续），第 6 笔支付完成即获 P2 生产资格。删除 P3/P4 研发入口（UI 与 action 签名收窄为 `'P2'`），类型定义保留 P3/P4 字段以兼容存档但无入口。

### 4.8 市场开拓与 ISO（年度模型）

统一为"年度投资"模型：`{ requiredYears, yearsInvested, investedThisYear }`。

- 市场：区域 1 年、国内 2 年、亚洲 3 年、国际 4 年；本地初始已准入。每年最多投 1M。
- ISO：ISO9000 ≥2 年、ISO14000 ≥3 年；每年各最多投 1M。
- **投资窗口仅 Q4**（年末操作"新市场开拓/ISO资格认证投资"，与控制表行对应）；投资按钮在非 Q4 禁用并提示。`yearsInvested ≥ requiredYears` 即获准入/认证；中途可停（不投即中断，进度保留）。
- **维持规则**：年末结账时检查每个已准入市场，本年未投 1M 维护者丧失准入（状态重置、日志警告）。本地市场同样适用（课程 _18 页"所有已进入的市场"）。ISO 认证完成后不需维持。

### 4.9 订单池（年初订货会）

课程材料无固定需求预测表（PDF 第 20 页为多组竞单示例，模式已废弃）。设计为**可配置的确定性订单池**：

- `src/config/marketDemand.ts`：按 `年 × 市场 × 产品` 给出订单数量与单价区间（初始数值参照经典用友 P1/P2 需求曲线拟定，标注"可由教师按课程实际数据修改"）。
- 每年 Q1"参加订货会"步骤：为每个**已准入市场 × 已有资格产品**生成订单（产品类型、数量、单价、总额、账期 1–4Q），广告投入金额决定**可选订单数量上限**（如 每 1M 广告解锁 2 张订单，取整），体现"市场订单数量有限，需结合市场需求合理投放广告"。
- 删除手工录入订单入口 `addAvailableOrder` 的 P3/P4 选项；手工录入保留（教师补单用）但默认折叠。
- 广告投放维持已实现的合并规则（一次覆盖本地+区域、P1+P2），投放时机限 Q1 年初订货会前后（订货会选单前必须已投放，否则提示）。

### 4.10 P1/P2 范围与高利贷

- 订单表单、订单池、研发、生产可选产品收窄为 P1/P2。
- 运营步骤表文案合规化："申请短期贷款（高利贷）"改为"申请短期贷款"；"向其他企业购买原材料/出售原材料"与"向其他企业购买成品/出售成品"两行改名"（本项目未启用）"并置灰。

### 4.11 其他修复

- `selectOrder` 去重（合并进 `moveOrderToSelected`）。
- 维护费移至年末：仅对"安装完工年份 < 本年且本年未出售"的生产线收 1M/条（课程 _22 页）。
- 小厂房租金 3M/年移至年末支付（初始大厂房自有、小厂房租赁，与初始资产负债表土地建筑 40M 一致）；年末步骤"支付租金/购买厂房"。厂房买卖操作不在本次范围（见第 8 节）。
- 长贷利息从 Q1 移至 Q4 年末支付。

### 4.12 运行控制表

**数据层**：`FinanceLog` 增加 `stepId`（如 `'q-5'`、`'y-2'`、`'b-1'`（年初）、`'e-6'`（年末））。所有产生现金变动或重要状态的 action 与 `nextQuarter` 内部事件在写日志时打标。季初盘点/结余等存量数据从季度存档快照读取（自动存档已按年/季保留）。

**stepId 映射**：年初 `b-1 新年度规划会议、b-2 参加订货会/登记销售订单、b-3 制定新年度计划、b-4 支付应付税`；季度 `q-1..q-20`（与《未命名》20 行一致）；年末 `e-1 支付利息/更新长期贷款/申请长期贷款、e-2 支付设备维护费、e-3 支付租金/购买厂房、e-4 计提折旧、e-5 新市场开拓/ISO资格认证投资、e-6 结账`。

**导出**：`exportYearControlTable(year)` 生成 `第X年运行控制表.csv`：

- 表头两行（标题跨列占位 + `序号,操作名称,季度1..季度4`）。
- 年初 4 行、年末 6 行：数据填在"季度1"列或独立"数值"列（采用：填在季度1列，序号独立编号）。
- 季度 20 行 × 4 季列：该季有事件填数据串，无事件但步骤自动完成填 `✓`，否则留空。
- 数据串格式遵循《你需要写一个……》：如盘点 `(现金,原料,产品)`、行 5/6 `3*R1`、行 10 `-1M(P1,全自动)`、行 17 `-11M(广告费)`、行 20 结余等。
- UI：运营流程页按年提供"导出第X年运行控制表"按钮（有数据的年份可点），保留现有总表展示。

### 4.13 UI 补齐

- **规则说明弹窗**：页头"规则说明"按钮，纯 React modal（不加依赖），内容分节：修改后广告规则、市场开发与维持、订单争取、厂房/生产线（含折旧/维护/出售）、采购与生产、研发、ISO、融资与贴现、费用/折旧/税金。文案取自 `.agents/documents/用友ERP沙盘模拟规则说明文件.md` 并按修改项校正。
- **暂停/继续**：store `isPaused`；暂停时所有变更类 action 直接返回并提示，页头显眼横幅 + 按钮。重置已有。
- **贴现面板**：财务中心，输入 7 的倍数金额，显示可贴现余额与预计到账。
- **时机门控**：长贷/短贷申请、市场与 ISO 投资、广告投放按 4.2/4.8/4.9 的窗口启停，非窗口期按钮禁用 + 说明。

### 4.14 存档与迁移

`SaveFile.version` 升为 2。加载 v1 存档时做默认值合并（新增字段取默认，`arrivalPeriod` 换算为绝对索引近似值），并在 UI 提示"旧存档已迁移，建议重置开新局"。自动存档保留每季度一份（现有机制确认/补齐）。

## 5. 数据流

UI 组件 → store action（校验规则窗口与额度）→ 状态变更 + `FinanceLog(stepId)` + 年度台账累计 → `nextQuarter`/年末结账推进 → 自动存档快照 → 控制表导出器从日志+快照推导 CSV。导出器为纯函数（输入日志与快照，输出字符串），便于单元测试。

## 6. 错误处理与规则校验

- 所有校验失败以 `validationError` 状态字段 + UI toast 呈现（现有模式沿用），不抛异常中断。
- 违规操作一律拒绝：超额贷款、非窗口期操作、贴现非 7 倍数、缺料生产、现金不足支付。
- 年末放弃市场的日志用 warning 级别醒目展示。

## 7. 测试策略

新增 vitest（devDependency），针对纯逻辑与 store：

1. 折旧（floor、<3M 提 1M、当年建成免提）。
2. 年度利润与税金（含亏损年税 0、下年初交纳）。
3. 长贷生命周期（3 年付息、到期还本、40M 上限）；短贷（Q1/Q3 窗口、到期本息）。
4. 贴现（7:1、倍数校验、余额校验）。
5. 原料到货跨年（Q3/Q4 下单次年 Q1/Q2 到货）。
6. 加工费扣现金与缺料拒绝。
7. 研发分期与中断续投；ISO/市场年度模型与维持放弃。
8. 控制表导出器：脚本化 1 年运营后断言关键单元格文本。
9. 订单池生成（市场/资格门控、广告解锁上限）。

UI 不做自动化测试，以 `npm run build` + 手工冒烟（下一季度全流程、导出 CSV）验证。
